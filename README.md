# Minesweeper Remake
This is a 2D remake of a popular game called Minesweeper. The remake was developed in Java programming language using the IntelliJ IDEA IDE.
The game uses attributes from Java Swing that provides better gaming experience.

## Features
* All stats in the game can be loaded and saved
* All settings in the game are always saved
* The game has 3 levels of difficulty (Easy, Medium, Hard)
* Use mouse to open or flag cells
* The game has sound effects and also music in main menu
* The player wins when all mines are flagged; otherwise, the game ends when player has opened mine cell
* The player's score and time are updated after each reveal.
* First reveal is legal

## Controls
* **Left click on the board:** Reveal one cell
* **Right click on the board:** Flag one cell
* **Double left click on the stats row:** Delete one row of players stats
* **Right click on the stats row:** Open board of the game
